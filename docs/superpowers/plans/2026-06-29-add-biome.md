# Add Biome Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Biome as the repo-wide lint and format tool for the pnpm monorepo.

**Architecture:** Use one root `biome.json` and root package scripts. Do not add ESLint or Prettier unless Biome blocks a required file type during verification.

**Tech Stack:** pnpm workspace, Biome `@biomejs/biome@2.5.1`, TypeScript, React TSX, Svelte, CSS, JSON.

## Global Constraints

- Do not modify migration files.
- Put shared configuration at the repo root.
- Use Biome for linting and formatting; skip ESLint and Prettier for now.
- Leave `.scss` files untouched because Biome does not cover project Sass files.
- Enable Biome HTML experimental full support so Svelte files are checked.

- Modify: `package.json`

## Task 1: Install Biome and Add Scripts

**Files:**
- Modify: `package.json`
- Modify: `pnpm-lock.yaml`

**Interfaces:**
- Produces root commands: `pnpm lint`, `pnpm lint:fix`, `pnpm format`, `pnpm format:check`.

- [ ] **Step 1: Add the root dev dependency**

Run:

```bash
pnpm add -D -w @biomejs/biome@2.5.1
```

Expected: `package.json` has `@biomejs/biome` in root `devDependencies`; `pnpm-lock.yaml` is updated.

- [ ] **Step 2: Add root scripts**

Update root `package.json` scripts to include:

```json
{
  "lint": "biome check .",
  "lint:fix": "biome check --write .",
  "format": "biome format --write .",
  "format:check": "biome format ."
}
```

Keep existing `build`, `dev`, and `type-check` scripts.

- [ ] **Step 3: Verify the binary resolves**

Run:

```bash
pnpm exec biome --version
```

Expected: prints `Version: 2.5.1`.

## Task 2: Add Root Biome Config

**Files:**
- Create: `biome.json`

**Interfaces:**
- Consumes: root scripts from Task 1.
- Produces: one repo-wide Biome config.

- [ ] **Step 1: Create `biome.json`**

Use:

```json
{
  "$schema": "https://biomejs.dev/schemas/2.5.1/schema.json",
  "vcs": {
    "enabled": true,
    "clientKind": "git",
    "useIgnoreFile": true
  },
  "files": {
    "includes": [
      "**/*.{js,jsx,ts,tsx,json,jsonc,css,html,svelte}",
      "!packages/server/migrations",
      "!packages/www/.svelte-kit"
    ]
  },
  "formatter": {
    "enabled": true,
    "indentStyle": "space",
    "indentWidth": 2,
    "lineWidth": 100
  },
  "linter": {
    "enabled": true,
    "rules": {
      "preset": "recommended"
    }
  },
  "assist": {
    "enabled": true,
    "actions": {
      "source": {
        "organizeImports": "on"
      }
    }
  },
  "javascript": {
    "formatter": {
      "quoteStyle": "double",
      "semicolons": "always",
      "trailingCommas": "all"
    }
  },
  "json": {
    "formatter": {
      "trailingCommas": "none"
    }
  },
  "html": {
    "experimentalFullSupportEnabled": true
  }
}
```

- [ ] **Step 2: Validate config shape**

Run:

```bash
pnpm exec biome check --no-errors-on-unmatched biome.json
```

Expected: command exits successfully or only reports formatting changes for `biome.json`; if it reports formatting changes, run `pnpm exec biome format --write biome.json`.

## Task 3: Run Biome and Apply Safe Fixes

**Files:**
- Modify only files Biome changes outside `packages/server/migrations/**`.

**Interfaces:**
- Consumes: `biome.json`.
- Produces: formatted code and safe lint fixes.

- [ ] **Step 1: Inspect current diagnostics**

Run:

```bash
pnpm lint
```

Expected: diagnostics may appear on the first run.

- [ ] **Step 2: Apply safe fixes**

Run:

```bash
pnpm lint:fix
```

Expected: Biome formats supported files, organizes imports, and applies safe fixes only.

- [ ] **Step 3: Re-run lint**

Run:

```bash
pnpm lint
```

Expected: exit code `0`. If Biome reports real bugs, fix the code. If it reports a noisy rule that is not useful for this repo, disable that exact rule in `biome.json` with a one-line reason in the commit message, not a broad preset downgrade.

## Task 4: Verify Existing Project Checks

**Files:**
- No planned file edits.

**Interfaces:**

- Produces: confidence that Biome did not break build/type/test workflows.

- [ ] **Step 1: Run type checks**

```bash
pnpm type-check
```

Expected: exit code `0`. If this still fails because of a pre-existing package issue, record the exact failure and run the package-level TypeScript checks that are relevant to files Biome changed.

```bash

```

Expected: exit code `0`.


Run:

```bash

git add packages
git commit -m "chore: add biome lint and format tooling"
```

Expected: commit succeeds.
